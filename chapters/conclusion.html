第12章 3行の結論をほどく

トップページの3行を、数字と平易な言葉に分解します。最後に「では何が一番勝てるのか」まで書きます。

1行目：リターンは増えるが、効率は変わらない#

Sharpe（シャープレシオ）は「値動き1単位あたり、どれだけ余分に稼いだか」を表す数字です。式は (リターン − 安全資産の利子) ÷ 値動きの荒さ。ただの割り算です。

レバレッジをL倍にすると、分子（リターン）も分母（値動き）もほぼL倍になります。割り算は、両方を同じ数で掛けても答えが変わらない。だからSharpeはほぼ動きません。

Sharpeは0.42〜0.54でほぼ横並び。いっぽう最大DDは55%→98%へと大きく増えます。「効率は同じ、痛みだけ増える」とはこのことです。

厳密には、指数によって上下します。減価とコストがあるからで、S&P500は0.46→0.42→0.43、半導体は0.47→0.49→0.50。タダで倍率が上がるわけではありません。

レバレッジはメガネの度数に似ています。景色は大きく見えますが、見える情報は増えません。度数を上げるほど、歪み（減価）も増えます。

レバレッジは、リターンを何倍にするのか#

よくある誤解が「1倍が10年で3倍なら、2倍は6倍、3倍は9倍」というものです。答えはノーです。

1xが10年で2.7〜3.3倍になった局面だけを抽出して、同じ期間の2x・3xを数えました。

指数局面数2x 中央（最小–最大）3x 中央（最小–最大）
S&P500604.19（2.47–6.56）4.52（1.94–11.76）
ナスダック100694.20（1.41–6.16）4.03（0.21–7.76）
半導体（SOX）100.59（0.48–4.23）0.01（0.01–2.70）

10年一括。開始日を1か月ずつずらし、1xの倍率が2.7〜3.3倍に収まった窓のみ。

中央値は2xで4.2倍前後、3xで4.0〜4.5倍。素朴な6倍・9倍には程遠く、2xと3xもほぼ同じです。S&P500なら500万円が、1x 1,500万円・2x 約2,100万円・3x 約2,260万円。

理由は2つあります。①調達金利（3倍なら2倍分の利息を10年分支払う）②ボラティリティ減価。式にするとこうです。

log(倍率_L) ≈ L×log(倍率_1) - 0.5×L(L-1)×σ²×年数 - (L-1)×金利×年数

S&P500（σ=17%、金利4.5%、10年、1x=3倍）で計算すると、2xは4.3倍、3xは4.6倍。実測の4.19倍・4.52倍とほぼ一致します。「6倍・9倍」の夢は、金利と減価で消えるということです。

幅も広い。同じ「1xが3倍」でも、S&P500の2xは2.47〜6.56倍、3xは1.94〜11.76倍でした。極端な例では、SOXが1994年9月〜2004年8月に3.1倍になった同じ10年で、3xは0.01倍（−99%）です。指数が3倍でも、3倍が元本割れする。

そして「痛みに耐えれば効率が上がる」わけでもありません。Sharpeが同じとは、リスク1単位あたりの見返りが同じという意味です。増えるのは金額の振れ幅であって、効率ではありません。痛みは、大きく張ったことの代償です。

2行目：3倍は2倍の代替にならない#

2倍と3倍を並べると、3倍のリターンは2倍と同じか、それ以下です。なのに最大DDは必ず重くなります。

指数2x CAGR3x CAGR2x 最大DD3x 最大DD
S&P500+13.4%+13.4%87.5%97.9%
ナスダック100+19.8%+17.3%98.7%99.975%
半導体（SOX）+13.2%-3.6%99.8%99.999%

理由は減価の式にあります。減価の係数は 0.5×L×(L−1)。L=2なら1、L=3なら3です。倍率を1つ上げるだけで、削られる力が3倍になります。

30年積立の勝率でも、2倍が98〜100%、3倍が82〜90%。「3倍は2倍の上位版」ではなく「別の商品」です。

ただし、一方向に上がり続けた期間では3倍が圧勝します（1990年代のSOXは10年で14.6倍）。だから「使うな」ではなく、「2倍の代わりにはならない」が正確なところです。

3行目：σ < √(2μ/L) の読み方#

この式は「値動きの荒さ（σ）が、この線を超えたら、そのレバレッジは1倍に負ける」という意味です。μは指数が稼ぐ力、Lは倍率。

導出は3行で終わります。

  1. L倍の期待対数リターンは Lμ − 0.5L(L−1)σ²（μは1xの対数成長率、コストを除く）
  2. 1倍は μ
  3. 差を取ると (L−1)(μ − 0.5Lσ²)。これが正になる条件が σ² < 2μ/L
指数1x CAGRσ（実現）σ*（3倍の閾値）余裕（σ*−σ）判定
S&P50010.9%17.1%26.3%+9.2%余裕あり
ナスダック10015.3%25.8%30.8%+5.0%ぎりぎり
半導体（SOX）15.9%37.9%31.3%-6.6%明確に不利

S&P500は余裕、ナスダック100はぎりぎり、SOXは明確に不利。この1行で3指数の答えが分かれます。

金利も効きます。調達コストを引くと実効のμが下がるので、閾値も下がります。0%と4.5%で3倍のCAGRは23.8%→13.2%（第02章）。

実務ではμに1倍の対数成長率 ln(1+CAGR) を使います。CAGRそのものより小さいので、閾値は低め（厳しめ）に出ます。安全側の判定です。

積みレバを入れると、どこが変わるか#

ここまでの3行は一括投資の話です。毎月積み立てると、同じ指数・同じ倍率でも順位が変わります。理由は単純で、積立は暴落のあとに必ず買うからです。3倍は下げが深いぶん、安く拾える量が増えます。

指数期間1x 中央 / 元本割れ2x 中央 / 元本割れ3x 中央 / 元本割れ3xが2xに勝つ割合
S&P50010年1.93倍 / 2%2.53倍 / 6%2.90倍 / 12%61%
S&P50020年3.41倍 / 0%5.25倍 / 0%6.08倍 / 7%69%
S&P50030年5.51倍 / 0%10.79倍 / 0%12.42倍 / 0%64%
ナスダック10010年2.26倍 / 3%3.92倍 / 20%5.43倍 / 27%62%
ナスダック10020年3.74倍 / 0%4.24倍 / 1%4.88倍 / 21%57%
ナスダック10030年11.07倍 / 0%23.65倍 / 0%23.27倍 / 0%49%
半導体（SOX）10年1.72倍 / 15%2.15倍 / 40%2.35倍 / 42%41%
半導体（SOX）20年4.79倍 / 0%8.72倍 / 0%10.07倍 / 4%69%

元本割れは「倍率が1.0未満だった窓の割合」。開始月を1か月ずつずらして全通り。

  • 変わる：3xは2xに劣らない場面がある。10年の中央値は3指数すべてで3xが2xを上回りました（2.90 vs 2.53、5.43 vs 3.92、2.35 vs 2.15）。S&P500は30年でも3xが上（12.42 vs 10.79）。
  • 変わらない：代償は元本割れの確率。10年で見ると、2xの元本割れは6〜20%、3xは12〜27%。SOXに至っては2xが40%、3xが42%で、そもそも10年では分が悪い。
  • 変わる：Sharpeの話は使えなくなる。拠出が時間で変わるので、Sharpeの分母（値動き）が一定になりません。代わりに見るのは「元本割れ確率」と「下位10%」です。
  • 変わらない：σ*の判定。あれは「一括で持ったとき長期で負けるか」の式。積立は負けを消しませんが、時間をかけて平均単価を下げるので、確率の形が変わります。

SOXの10年は特に分かりやすい例です。3xの中央値は2xより高いのに、3xが2xに勝つのは41%しかない。つまり勝つときは大きく勝ち、負ける回数はもっと多い。中央値だけ見ると誤解します。

積立は「3倍が2倍に勝つ」ように見えますが、勝率が上がったわけではありません。負けたときの額が大きくなり、勝ったときの額も大きくなっただけ、という面があります。30年なら元本割れはどれも0%ですが、途中のDDは3xが圧倒的に深い。

1番勝てるパターン#

判定基準を先に決めます。「10年で元本を割りにくい（下位10%が1.0倍以上）」＋「中央値が高い」。開始年を1年ずつずらして全通り試しました（10年・各指数の全開始年）。

基準を「負けない」に置くか「勝ち額」に置くかで答えが変わります。勝ち額なら3x系（NDXは中央6.43倍）ですが、下位10%は0.56倍まで沈みます。ここでは負けないを優先しました。

  • S&P500：2x + DD20 + 初期100万円が中央2.89倍・下位10%1.28倍で最良。ただし素の2x（2.50／1.18）との差は主に「初期100万円を先に入れた」効果で、DD20単体では2.47／1.13とほぼ同等でした。
  • ナスダック100：同じ組み合わせが中央5.75倍・最悪0.68倍で最良。こちらはDD20単体でも3.98→4.38と改善します。
  • SOX：2x + DD20（1.97倍／下位10%0.48倍）。初期100万円を足すと1.81倍に下がります。高値づかみになるためです。

総合すると、土台は「2倍 ＋ 高値から20%下がった月は倍額」。初期資金の上乗せはS&P500とナスダック100では効きますが、SOXでは逆効果。しかも上乗せの効果は「早く大きく入った」ことに由来するので、相場観の優位ではありません。

運用に落とすと

  • 毎月3万円を2倍（SSO、QLD など）で積立。SPXLは3倍なので使わない。
  • 指数が直近高値から20%下がった月は6万円。
  • そのための現金を別枠で最低72万円（1年分）。
  • 3倍は使わない。使うなら余剰資金の一部だけ。
これは1970-2026年の1つの相場を後から数えた結果です。戦略8通り×3指数、さらに10年の窓を全開始年で見ているので、偶然の勝ちは必ず混ざります。「下位10%が1.28倍」も保証ではありません。
